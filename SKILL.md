# Слайды в Figma через плагин

Claude пишет плагин из шаблона `template/`, пользователь запускает его в Figma, Claude проверяет результат и правит. Плагин работает внутри Figma и не тратит запросы API.

## Почему так, а не через API

- REST API Figma не создаёт и не меняет объекты на холсте, с любым токеном.
- Официальный MCP-сервер Figma умеет писать на холст (`use_figma`, бета с февраля 2026), но для записи нужно место Full. На местах View и Collab лимит до 20 вызовов в месяц на любом тарифе, поэтому на бесплатном тарифе его хватит на пару попыток. Если у пользователя платный тариф с местом Full, предложи сначала MCP, а этот скилл держи запасным вариантом.
- REST API для чтения ограничен так же: на местах View и Collab до 20 запросов в месяц. Поэтому API используем только для проверки и экономно (раздел «Проверка»).

## Что нужно от пользователя

1. Приложение Figma для компьютера: свой плагин из папки запускается только в нём.
2. Файл типа **Design** с правом редактирования. На бесплатном тарифе не больше 3 страниц, поэтому колоды кладём секциями на одну страницу.
3. Сценарий: какие слайды, с каким текстом. Если есть старая презентация, сначала составь по ней сценарий и согласуй его с пользователем.
4. Стиль: оставить тему шаблона или подстроить под свой. Свои цвета и шрифты задаются в `THEME` в начале `code.js`. Шрифты берите из Google Fonts: они есть в Figma у всех.
5. По желанию — готовые слайды для копирования (`clone`). Их нужно скопировать в целевой файл, плагин видит только его.

## Порядок работы

1. **Скопируй шаблон** `template/` в папку проекта пользователя, например `figma-plugin/`. Скилл не меняй.
2. **Заполни `DECKS`** в `code.js`: по колоде на презентацию, слайды — макетами из `references/layouts.md`. Пример колоды в шаблоне замени. В `RUN` оставь только колоды, которые собираешь сейчас.
3. **Проверь без Figma.** Скопируй `tests/smoke-test.js` к плагину пользователя, поправь путь к `code.js` и ожидания под его колоды (сейчас тест ждёт пример из шаблона), прогони `node smoke-test.js`. Тест ловит падения, слова шире блока и текст за краем. Ширину букв он оценивает приблизительно, поэтому тонкие переносы видны только в Figma. Минимум — `node --check code.js`.
4. **Пользователь подключает плагин один раз:** меню Figma → Plugins → Development → Import plugin from manifest → `manifest.json`. Дальше только Plugins → Development → Slides builder. После правок кода переимпортировать не нужно: плагин читает файл при каждом запуске.
5. **Пользователь присылает итоговое сообщение плагина.** «Готово — …: N слайдов. Предупреждений нет» — переходи к проверке. «⚠ Предупреждений: …» — это слова шире блока или текст за краем: исправь, в консоли разработчика Figma полный список. «Ошибка: …» — плагин остановился, текст ошибки говорит, что не так.
6. **Проверь глазами** (раздел ниже), исправь данные, попроси перезапустить. Повторный запуск пересобирает только секции из `RUN`.
7. **Закончил колоду — убери её из `RUN`.** Иначе следующий запуск сотрёт ручные правки, которые пользователь сделал в Figma.

## Проверка

Сообщение плагина ловит самое частое, но смотреть глазами всё равно нужно: на наложения, пустоты и смысл.

- **Браузер, без лимитов** (Claude in Chrome). Открой файл, выдели в списке слоёв первый слайд колоды, нажми Shift+2, затем листай клавишей N: каждое нажатие переходит к следующему фрейму и приближает его. Снимай область слайда действием `zoom`. Между нажатием и снимком жди 2 секунды, иначе Figma не успевает дорисовать. Ничего не перетаскивай и не нажимай на холсте: смотришь в чужом рабочем файле.
- **API, один батч на колоду:** `FIGMA_TOKEN=… python3 scripts/figma_render.py <file_key> "<секция>" <папка> --refresh` — два запроса на всю колоду. Не запускай по слайду. Получил 429 — переходи на браузер, повторять бесполезно до сброса месячного лимита.
- Токен Figma — только на чтение, хранится в `.env` или менеджере секретов. В чат его не выводить.

## Грабли

- **Длинное слово в узкой карточке рвётся посередине** («Публика/ция», «Пересказыв/ает»). Плагин предупреждает, а лечится коротким словом или меньшим числом карточек.
- **Перенос внутри «about-me.md» и цифра одна на строке.** Шаблон сам ставит неразрывный дефис и неразрывный пробел перед числом. «было → стало» и подобное склеивай неразрывными пробелами вручную: `"было → стало"`.
- **Квиз и ответ делай парой с одинаковыми данными:** карточки стоят на одном месте, при показе видно только, как подсвечивается ответ.
- **Пересборка стирает ручные правки** в секции. Сначала доведи плагином, потом пусть правят руками.
- **Удалил исходные слайды — их копии (`clone`) больше не пересобрать.** Удаляй старое только после того, как колоды, которые из него копируют, готовы и убраны из `RUN`.
- **После пересборки у слайдов новые id.** Для `figma_render.py` нужен `--refresh`, для `clone` по `ref` ничего не нужно.
- **Кавычки внутри строк данных.** `"«на "вы"»"` ломает код, а `„“` в Inter выглядят странно. Пиши «обращение на вы» или используй ёлочки.

## Файлы скилла

- `template/manifest.json`, `template/code.js` — плагин: тема, 14 макетов, сборка, предупреждения, пример колоды.
- `references/layouts.md` — поля каждого макета и сколько текста влезает.
- `tests/smoke-test.js` — проверка плагина без Figma: `node tests/smoke-test.js`.
- `scripts/figma_render.py` — картинки слайдов секции через API, одним запросом.
