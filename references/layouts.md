# Макеты слайдов

Каждый слайд в `DECKS` — объект с полями `type` и `name` и полями своего макета. Перенос строки внутри текста — `\n`. Размеры даны для слайда 1440×900 с полями 96 px, контентная ширина `CW` = 1248 px.

## Колода

```js
{ section: "Модуль 1 · Теория", prefix: "М1", footer: "Демо-колода · Модуль 1", slides: [ … ] }
```

- `section` — имя секции в Figma. По нему плагин находит и пересобирает колоду.
- `prefix` — начало имени каждого слайда: «М1 · 07 Таблица».
- `footer` — подпись внизу контентных слайдов. Не нужна — не указывайте.

## Макеты

| type | Для чего | Поля |
|---|---|---|
| `cover` | Обложка, тёмный фон | `title`, `top` (подпись справа вверху) |
| `statement` | Одна крупная фраза по центру | `text`, `sub` |
| `section` | Титул части | `label` (мелко сверху), `title` |
| `way` | Заголовок и плашка с полосой слева: пример запроса, команда | `label`, `title`, `box`; `command` — крупная строка над `box`; `accent` — цвет полосы; `wide` — на всю ширину; `boxSize`, `boxLh` |
| `cards` | 2–6 карточек в ряд | `title`, `sub`, `items: [{ n, k, h, t }]` (номер, подпись, заголовок, текст — всё кроме `h` по желанию), `note` |
| `table` | Таблица | `title`, `sub`, `headers` (по желанию), `cols` (ширины, в сумме 1248), `rows`, `highlight` (номер строки с подсветкой), `dense`, `size` |
| `compare` | Две плашки рядом | `title`, `sub`, `left: { label, text }`, `right: { label, text }`, `strong` (обвести правую), `note` |
| `flow` | 3–5 шагов со стрелками | `title`, `sub`, `steps`, `accent` (номер шага с 0, обвести зелёным), `note` |
| `definition` | Определение: номер и заголовок слева, текст и выноска справа | `num`, `title`, `def`, `calloutLabel`, `callout` |
| `code` | 1–2 блока кода | `title`, `sub`, `blocks: [{ label, code }]`, `size`, `note` |
| `quiz` | Вопрос и 4 варианта | `q`, `options` (4 штуки), `correct` (с 0), `answer: true` на слайде ответа, `hint` |
| `story` | Случай и вывод | `label`, `title`, `text`, `lesson`, `lessonLabel`, `source` (в подпись) |
| `example` | Команда → вход → результат | `title`, `command`, `input`, `output`, `footnote` |
| `clone` | Копия готового слайда из этого файла | `id` или `ref`, `edits`, `fit` — ниже |

## Сколько влезает

Плагин сам предупредит, если слово шире своего блока или текст вылез за край слайда. Ориентиры, чтобы не доводить до предупреждений:

- `cards`: при 5–6 карточках заголовок — одно-два коротких слова, до 10 букв в слове. «Публикация» в шести карточках уже не влезает.
- `flow`: при 5 шагах — до 4–5 слов в шаге, без слов длиннее 12 букв.
- `table`: до 5–6 строк по одной-две строчки текста.
- `quiz`: вариант ответа — до 60 символов.
- `statement`: до 15 слов.

## Копия готового слайда (`clone`)

Подходит, когда в файле уже есть удачный слайд, например со сложной иллюстрацией, и его нужно повторить или поменять в нём текст.

- `id` — номер фрейма. Выделите фрейм в Figma → Copy link to selection: в ссылке будет `node-id=12-345`, это `"12:345"`. API для этого не нужен.
- `ref` — точное имя фрейма в текущем файле, например готовый слайд из уже собранной колоды: `"М1 · 02 Камера"`.
- `edits: [["начало старого текста", "новый текст", { w: 600 }], …]` — заменить текст. `w` — новая ширина, если текст стал длиннее.
- `fit: "#ffffff"` — если исходный слайд другого размера, вписать его в 1440×900 с этим фоном.

Плагин видит только тот файл, в котором запущен. Слайды из другого файла сначала скопируйте в него (Cmd+C → Cmd+V). Если удалить исходный слайд, колоды, которые его копируют, пересобрать будет нельзя.
